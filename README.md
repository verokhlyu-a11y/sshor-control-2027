# СШОР Контроль

Учебный интерактивный прототип сайта в фирменном стиле СШОР. Использует HTML, CSS и JavaScript, без серверной части.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий `sshor-control` на GitHub.
2. Загрузите файлы `index.html`, `style.css`, `app.js`, `DESIGN.md`, `README.md` в корень репозитория.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветвь **main**, папку **/(root)** и нажмите **Save**.
5. После публикации сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/sshor-control/`.

## Важно

GitHub Pages — публичный статический хостинг. Не загружайте реальные персональные данные, внутренние документы и конфиденциальные сведения. Данные задач сохраняются в localStorage только на устройстве пользователя; они не синхронизируются между сотрудниками. Для полноценной многопользовательской системы понадобятся сервер, база данных и авторизация.
